# RaceLab

Plataforma de análise de Fórmula 1: resultados, campeonatos, perfis de pilotos e equipes, Telemetry Lab, Strategy Lab, Circuitos e Driver Wars. Site estático (HTML/CSS/JS puros) e PWA instalável.

## Rodar localmente
```bash
python -m http.server 8123
```
Abra http://localhost:8123

## Deploy
Site estático, sem build: na Vercel, importe o repositório com o preset "Other" (sem comando de build, diretório raiz).
